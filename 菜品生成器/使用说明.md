# 食材配菜生成器 · 使用说明（保姆级）

这个工具让你（或会员）**选好食材 + 选烹饪方式 → 一键出几道可选的菜**，还能点右下角小助手问“不知道吃啥”。

三个文件：
- `会员版-食材配菜生成器.html` —— 发给会员的网页（**里面不含任何密钥**，可以放心发）
- `代理-worker.js` —— 一段藏密钥的中转脚本（你部署一次）
- `使用说明.md` —— 就是本文件

> 为什么要“中转”？因为发给会员的网页谁都能看到源码。如果把密钥写进网页，会员一打开就能拿到你的密钥、把你的额度刷光。所以密钥藏在“中转代理”里，网页只调代理地址，安全。

## 一次性准备（你自己做，约 15 分钟，之后一劳永逸）

### 第 1 步：申请硅基流动 Key（约 5 分钟）

1. 打开 **https://siliconflow.cn** ，用手机号注册、登录。
2. 按提示完成**实名认证**（新用户有免费额度，DeepSeek 系列有免费模型，个人用基本够）。
3. 左侧菜单找到 **「API 密钥」**（英文界面是 API Keys）→ 点 **「新建 API 密钥」** → 复制那串 **`sk-` 开头**的字符。
   - ⚠️ 这串只显示一次，先粘到记事本存好。
   - ⚠️ **别用**你在开源文件里看到的那个别人的密钥：会失效、可能被封、花的是别人额度，靠不住。

### 第 2 步：部署中转代理（约 10 分钟）

1. 打开 **https://cloudflare.com** 注册、登录（免费）。
2. 左侧进入 **Workers & Pages** → 点 **Create**（创建）→ 选 **Create Worker** → 起个名字（随意，如 `caipei`）→ **Deploy**（先随便部署一版）。
3. 部署后点 **Edit code**（编辑代码）：把编辑器里原有内容**全部删掉**，把本目录里 **`代理-worker.js` 的全文**粘进去 → 右上角 **Deploy**（保存部署）。
4. 回到这个 Worker 的 **Settings（设置）→ Variables and Secrets（变量与密钥）**：
   - 点 **Add**（添加）→ 类型选 **Secret**
   - **Variable name（名字）**填：`SILICONFLOW_KEY`
   - **Value（值）**填：你第 1 步复制的 `sk-xxxx`
   - 保存（Deploy）。
5. 在 Worker 首页复制它的访问地址，形如 **`https://caipei.你的名字.workers.dev`**。这就是你的“代理地址”。

### 第 3 步：把代理地址填进网页

1. 用记事本 / VS Code 打开 `会员版-食材配菜生成器.html`。
2. 找到顶部这一行：
   ```js
   const PROXY_URL = 'https://你的代理地址.workers.dev';
   ```
   把引号里的内容换成第 2 步复制的真实地址，**保存**。
3. 完成 ✅ 之后这个 HTML 就能直接发给会员（微信发文件 / 传到你的网站都行）。

## 怎么用

- **会员**：双击打开网页 → ① 点选食材（家里没有的可在下方“补充食材”手动加）→ ② 选烹饪方式（可多选或“不限”）→ ③ 点「帮我配几道菜」→ 出 3~5 张菜卡（菜名 / 食材克重 / 做法 / 热量·蛋白 / 忌口提示），不满意点「再换一批」。
- **不知道吃啥**：点右下角绿色气泡，直接和小助手聊（清淡点 / 减脂 / 家里有啥），支持多轮对话。

---

## 验证是否成功

1. 打开网页，选「鸡蛋 + 西红柿」、烹饪方式「清炒」，点生成 → 应出现几张菜卡。
2. 点右下角气泡问一句，能正常回复。
3. **安全自查**：在网页上右键「查看网页源代码」，按 Ctrl+F 搜 `sk-` → **搜不到**才对（只应看到 workers.dev 代理地址）。

---

## 花钱与安全小贴士

- 会员用掉的 token 都算在**你的**硅基流动账号上。量大时，去硅基流动后台设**消费上限 / 用量提醒**。
- 想更稳：打开 `代理-worker.js`，把 CORS 里的 `*` 改成你放网页的域名；文件里还有两行“可选加固”（限定模型、限制输出长度）的注释，按需要打开。
- 换模型：网页顶部 `const MODEL = 'deepseek-ai/DeepSeek-V3'` 可改成硅基流动支持的其它模型名（比如某个免费模型以省钱）。

---

## 常见问题

- **点生成没反应 / 报错**：多半是代理地址没填对，或第 2 步的 `SILICONFLOW_KEY` 没配好 / 没实名。回到第 2、3 步核对。
- **提示接口 401 / 余额不足**：硅基流动 Key 无效或额度用完，去后台看。
- **出的菜没按 JSON 显示成卡片**：偶尔模型不守格式，网页会自动兜底把原文显示出来，点「再换一批」通常就正常了。
