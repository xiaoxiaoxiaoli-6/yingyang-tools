💡 为什么加"外食"和"运动"这两项？
• 外食 → 油盐不可控、体重可能短暂上涨（不是真胖），营养师需要知道这个背景
• 运动 → 消耗不同，饮食需要跟着调。跑步日 vs 力训日 vs 休息日，吃的不一样
• 外食是当天晚上收集，运动是当天让会员发你。都填在表格的"评价"行里，格式："外食 ✓ / 跑步5km"

💬 三种场景 · 回复框架（往里面填，不是复制粘贴）

每种场景给你一个结构。你按照结构，用自己的话填内容。这样每个会员的回复都不一样，不会显得重复。

✅ 场景A：会员按计划走了

框架（3句话就够）：

1️⃣ 具体夸一个细节 → 你看到了什么？（别只说"挺好的"，要说"杂粮饭量刚好""蔬菜颜色搭配好看""时间很准时"）

2️⃣ 跟之前比 → "比第一周进步好多""你连续X天都对了""现在搭配越来越熟练了"

3️⃣ 给明天一句话 → "明天继续保持这个节奏""照这样下去目标很快到"

⚠️ 变体：如果连续5天全对 → 第2句加重夸。"你是我见过最自律的会员之一了，连续5天全对，真的太稳了。"

⚠️ 场景B：会员没按计划走

框架（先问原因，再给建议）：

1️⃣ 先问一句 → 别上来就纠正。"今天这餐是外食了吗？""是饿了所以多盛了饭？""今天太忙了没来得及准备？"

2️⃣ 根据原因回应 →
   外食了，但有肉有菜有主食 → "外食能注意搭配已经很棒了！👏 涮一下水油能少大半，下次试试～"（先肯定，再给轻建议）
   外食了，但缺了某样（比如只有面/只有肉，没蔬菜） → "外食确实难控制～不过你注意到没，今天这餐少了蔬菜/主食/蛋白质。下次外食可以盯着三个东西点：一份肉+一份菜+一份主食，这样结构就对了。"
   饿了所以多吃了 → "说明上餐量可能不太够，我帮你记下来反馈给营养师看看。"
   忘了/太忙没准备 → "没事，明天回归正常就行，一顿不影响💪"

3️⃣ 给一个简单动作 → 只说一个，别列清单。"明天午餐主食少盛1/3" 或 "下顿加一把蔬菜"

⚠️ 核心：先搞清楚为什么没按计划走，才能给对建议。外食不是问题，外食没按"有肉有菜有主食"的结构来才是问题。上来就说"你吃多了"——这是最没用的回复。

💬 场景C：会员说了话，需要认真回应

框架（接住三个东西）：

1️⃣ 接住情绪 → 她说了什么情绪词？（焦虑/愧疚/困惑/开心）先回应这个。
   "哈哈没事的""我理解你的担心""哇这么开心！"

2️⃣ 回应事实 → 她说了什么具体事情？（吃多了/没掉秤/累了/姨妈来了）给一个简单解释。
   "一顿吃多不会胖的""姨妈前后囤水很正常"

3️⃣ 给下一步 → 她接下来该干嘛？一句话说清楚。
   "今晚主食减1/3就好""这两天别称体重""明天正常吃回来"

⚠️ 自检：回之前看一眼，会员说了A/B/C，你至少接了其中两个吗？只接一个 = 敷衍。

❌ 敷衍的例子
会员："今天中午吃撑了好难受啊😭感觉坚持不下去了"
助理："好的收到，晚餐记得按计划吃。"
← 情绪没接、事实没回应、下一步太笼统。三样全没接住。
✅ 按框架来
会员："今天中午吃撑了好难受啊😭感觉坚持不下去了"
助理："哈哈吃撑了说明你享受了美食呀～一顿真的不会胖的，别给自己太大压力🙌 今晚可以把主食减1/3，散散步帮助消化，明天就恢复正常了。你能坚持到现在已经很厉害了，别放弃💪"
← 情绪✓ 事实✓ 下一步✓

🔇 去AI味（每次发之前扫一眼）

  • "建议您" → "可以试试" / "下次可以"
  • "摄入量" / "摄入" → "吃的量" / "吃的"
  • "控制" → "注意一下" / "少一点"
  • "超标" → "比计划多了一点"
  • "此外" / "另外" / "同时" → 删掉，直接说下一句
  • "根据您的计划" → "你的计划里" / "按你计划"
  • 回复超过6行 → 控制在4-5行，长了没人看
  • 每句话都加表情 → 每2-3句加一个就行
  • 直接复制AI答案 → 读一遍，用自己的话重说。问自己：我对朋友会这么说话吗？

不需要单独写一段文字发我。你只需要把在线表格填好+标红，我打开表格就全看到了。

📌 每晚你只需要做：
1. 确认当天所有会员的数据都填进表格了
2. 按标红规则，把异常格子底色标红
3. 标红的 = 需要我关注的 → 我会在表格里一眼看到
4. 如果有特别紧急的事（比如会员说身体不舒服、想放弃），单独私聊我
🔴 标红 = 需要我关注。表格是在线的，你标红了我就看得到。
不需要再打一段字告诉我"xxx体重3天不动"——我打开表格，红色格子自己会说话。

✅ 每天下班前自查（3个问题）

  • 今天所有会员的打卡我都回了吗？有没有漏的？漏一个，会员明天就不想打卡了。
  • 我的回复有没有"好的""收到""不错"就完了？有的话，现在补一句具体的。按框架补。
  • 今天的汇总发了吗？标红的都写进"需要关注"了吗？体重3天不动 / 排便2天无 / 睡眠<6h → 必须标红上报。
